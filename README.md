## Stack

Next.js | TypeScript | Tailwind CSS | GSAP | Lenis | Resend

## Run locally

```bash
npm install
npm run dev
```

Create `.env.local`:

```
RESEND_API_KEY=your_key
CONTACT_TO_EMAIL=you@example.com
```
